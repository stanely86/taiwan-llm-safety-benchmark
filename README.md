# taiwan-llm-safety-benchmark
Engineered an automated LLM red teaming pipeline using Promptfoo to expose safety vulnerabilities across Hallucination, COPPA, and Cybercrime vectors. Processed the raw CSV evaluation data to design and build an interactive Tableau dashboard. This one-page report visualizes pass/fail/error rates and categorizes model blind spots, translating complex adversarial testing results into actionable AI safety insights.
